# N-frame effect shaders

Shaders that use the patch's window of frames for something other than interpolation (2026-10-25). The why, what they
showed and what to build next: [BEYOND-INTERPOLATION.md](../../BEYOND-INTERPOLATION.md).

Each is an **N:N filter**: run it at the source's own frame rate, so it sees a window centred on every frame.

```sh
ffmpeg -i in.mkv -vf "libplacebo=fps=24000/1001:frame_mixer=custom_n:custom_shader_path=chronophotograph.glsl" out.mkv
```

| file | window | what it does |
|---|---|---|
| [chronophotograph.glsl](chronophotograph.glsl) | 8 | the still world with the last five frames' movers laid on it as fading exposures |
| [ghost-town.glsl](ghost-town.glsl) | 7 | each pixel's median over the window: fast movers vanish (`GHOST_MOVERS = 1`: only the movers) |
| [ghost-town-long.glsl](ghost-town-long.glsl) | 7 + storage | the median over a 12-frame ring kept in storage (three seconds at 24 fps) and the window |
| [long-exposure.glsl](long-exposure.glsl) | 2 + storage | a running exposure: light painting (`LIGHT_PAINT = 1`) or shutter drag |
| [pulfrich.glsl](pulfrich.glsl) | 5 | red eye now, cyan eye two frames ago: lateral motion reads as depth |
| [spectrum.glsl](spectrum.glsl) | 8 | each pixel's temporal Fourier energy, trend removed; hue the frequency |
| [tremor.glsl](tremor.glsl) | 7 | Eulerian magnification of small change, large motion left alone |

**Editing:** each `.glsl` is generated by [gen_effects.py](gen_effects.py) from its `.body.glsl`, which adds the shared
prelude: the frame binds, `F(k, pos)` (slot k's colour), `T(k)` (its time from `rts_mix`, in source frames), `L()` (luma)
and `NOW()` (the slot nearest the output). A body declares `// WINDOW n` and `// DESC ...`, and optionally
`// TEXTURE name w h format`, `// BIND name` and a `// PREPASS BEGIN` ... `// PREPASS END` pass that must run first.
Edit the body, then run `python3 gen_effects.py`.

**Things learned building them:** the window's slots are not in time order (use `rts_mix`); a pass binds at most 16
textures (tile a ring of frames into one storage texture); `//!` inside a comment is read as a directive; a counter
written by one pixel and read by the others in the same pass races (give it a 1 x 1 pass of its own); the first and last
few frames of a clip fall back to the builtin mixer.
